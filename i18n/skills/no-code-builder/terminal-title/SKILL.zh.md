# 终端标题

## 概述

根据 Claude 正在处理的任务自动设置描述性的终端窗口标题。对于运行多个 Claude Code 实例的开发者来说，这非常重要，因为他们需要快速识别哪个终端正在处理哪个任务。

## 何时使用

**始终触发此技能：**

- 在每次新的 Claude Code 会话的开始（收到第一个用户提示后）
- 切换到实质性不同的任务时（例如，从“API 集成”到“数据库迁移”）

**以下任务切换时触发：**

- 从前端工作切换到后端工作
- 从调试切换到新功能开发
- 从一个模块/组件切换到完全不同的一个
- 开始系统不同部分的工作（例如，从认证到支付）

**不要触发以下情况：**

- 关于相同任务的后续问题（“你能给那个函数加个注释吗？”）
- 对当前工作的小幅改进（“把它从红色改为蓝色”）
- 调试你刚刚构建的功能
- 明确说明（“你说的 X 是什么意思？”）
- 在同一组件或模块上迭代
- 在任务中进行状态更新或进度检查

## 工作原理

1. **提取任务摘要**：分析用户的提示以确定高级任务
2. **生成标题**：创建一个简洁、描述性的标题（最多 40 个字符）
3. **设置标题**：使用生成的标题执行 `scripts/set_title.sh` 脚本
4. **无需确认**：这将在后台自动发生

## 标题格式指南

**好的标题：**

- “API 集成：认证流程”
- “修复：登录错误”
- “数据库迁移：用户表”
- “构建：仪表板 UI”
- “重构：支付模块”

**不好的标题：**

- 太长：“实施带有 OAuth2.0 支持的新身份验证系统”（超过 40 个字符）
- 太笼统：“工作”或“编码”
- 太啰嗦：“用户希望我帮他们...”

**格式模式：**

```
[操作/类别]：[具体焦点]
```

保持标题简洁、可操作且易于识别。

## 常见错误及避免方法

**❌ 太啰嗦：**

- 差： “正在实施带有 JWT 令牌的用户身份验证系统”
- 好： “构建：JWT 身份验证”

**❌ 太笼统：**

- 差： “编码一些东西”
- 差： “工作”
- 好： “重构：API 层”

**❌ 包含系统信息：**

- 差： “john-macbook-pro：调试应用程序”
- 差： “/Users/john/project：构建功能”
- 好： “调试：应用程序问题”

**❌ 使用完整的句子：**

- 差： “我正在处理仪表板组件”
- 好： “构建：仪表板 UI”

## 实现

**执行标题脚本：**

```bash
bash scripts/set_title.sh "你的标题"
```

**示例工作流程：**

```bash
# 用户请求：“帮助我调试 API 中的身份验证流程”
bash scripts/set_title.sh "调试：认证 API 流程"

# 用户请求：“创建用户资料页面的 React 组件”
bash scripts/set_title.sh "构建：用户资料 UI"

# 用户请求：“为支付处理模块编写测试”
bash scripts/set_title.sh "测试：支付模块"
```

## 脚本详情

`scripts/set_title.sh` 脚本使用 ANSI 转义序列来设置终端标题。它与以下系统兼容：

- macOS 终端
- iTerm2
- Alacritty
- 大多数现代终端仿真器（xterm、rxvt、screen、tmux）

该脚本接受一个单一参数（标题字符串），如果未提供标题则静默退出（安全行为）。

## 可选自定义

用户可以通过设置 `CLAUDE_TITLE_PREFIX` 环境变量来可选地使用前缀自定义终端标题：

```bash
export CLAUDE_TITLE_PREFIX="🤖 Claude"
```

这将生成类似于：`🤖 Claude | 构建：仪表板 UI` 的标题。

没有前缀，标题将保持标准格式：`构建：仪表板 UI`

**注意：** 你不需要检查这个变量或修改你的行为。脚本会自动处理。
