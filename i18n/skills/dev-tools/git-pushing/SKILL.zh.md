# Git 推送工作流

阶段化所有变更，创建传统的提交信息，并推送到远程分支。

## 使用场景

当用户满足以下条件时，会自动激活：

- 明确要求推送变更（“推送这个”、“提交并推送”）
- 提及保存工作到远程（“保存到 GitHub”、“推送至远程”）
- 完成一个特性并希望分享它
- 说出类似“让我们把这个推上去”或“提交这些变更”的短语

## 工作流

**始终使用脚本** - 不要使用手动 Git 命令：

```bash
bash skills/git-pushing/scripts/smart_commit.sh
```

使用自定义信息：

```bash
bash skills/git-pushing/scripts/smart_commit.sh "feat: 添加功能"
```

脚本处理：阶段化、传统的提交信息、Claude 页脚、使用 -u 标志推送。
