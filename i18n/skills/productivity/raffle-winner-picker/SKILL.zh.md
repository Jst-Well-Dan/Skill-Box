# 抽奖获奖者选择器

此技能可以随机从列表、电子表格或 Google Sheets 中选择获奖者，用于赠品和竞赛活动。

## 使用此技能的时机

- 运行社交媒体赠品活动
- 在活动中挑选抽奖获奖者
- 随机选择调查或测试的参与者
- 从竞赛提交中选择获奖者
- 公平分配有限的席位或资源
- 随机分配团队

## 此技能的功能

1. **随机选择**：使用加密随机选择
2. **多个来源**：支持 CSV、Excel、Google Sheets 或纯列表
3. **多个获奖者**：可以选取一个或多个获奖者
4. **重复预防**：确保同一个人不能两次获奖
5. **透明结果**：清楚地显示选择过程
6. **获奖者详情**：显示所有关于获奖者的相关信息

## 使用方法

### 从 Google Sheets 中选择

```plaintext
从以下 Google Sheets 中随机选择一行以选择赠品活动的获奖者：[工作表 URL]
```

### 从本地文件中选择

```plaintext
从 entries.csv 中选择 3 个随机获奖者
```

### 从列表中选择

```plaintext
从以下列表中选择一个随机获奖者：
- Alice (alice@email.com)
- Bob (bob@email.com)
- Carol (carol@email.com)
...
```

### 选择多个获奖者

```plaintext
从 contest-entries.xlsx 中选择 5 个随机获奖者，确保没有重复
```

## 功能

### 公平选择
- 使用安全的随机数生成
- 没有偏见或模式
- 透明的过程
- 可重复（用于验证）使用种子

### 排除
```plaintext
排除前获奖者选择随机获奖者：Alice, Bob, Carol
```

### 加权选择
```plaintext
根据 "entries" 列（1 条条目 = 1 张券）的加权概率选择获奖者
```

### 备选获奖者
```plaintext
从列表中选择 1 个获奖者和 3 个备选获奖者
```

## 示例工作流程

### 社交媒体赠品活动
1. 从 Google 表单导出条目到 Sheets
2. "从 [工作表 URL] 中选择一个随机获奖者"
3. 核实获奖者详情
4. 公开宣布并注明时间戳

### 活动抽奖
1. 创建包含参会者姓名和邮箱的 CSV 文件
2. "从 attendees.csv 中选择 10 个随机获奖者"
3. 导出获奖者名单
4. 直接给获奖者发邮件

### 团队分配
1. 有参与者列表
2. "将此列表随机分成 4 个相等的团队"
3. 检查分配情况
4. 分享团队名单

## 小贴士

- **记录过程**：保存时间戳和方法
- **公开宣布**：分享选择详情以保持透明度
- **核实资格**：验证获奖者是否符合竞赛规则
- **备选方案**：选择备选获奖者以防获奖者不符合资格
- **导出结果**：保存获奖者名单以备记录
