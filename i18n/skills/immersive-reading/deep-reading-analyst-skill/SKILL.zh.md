# 深度阅读分析师

通过系统思维框架将表面阅读转化为深度学习。

## 此技能的功能

提供结构化分析工作流程，使用5种经过验证的思维框架在4个深度级别（15分钟到120分钟以上）进行。通过可操作的结果，指导用户从理解到应用的转化。

## 何时使用此技能

当用户：
- 分析复杂文章、论文或长篇内容
- 评估论点并识别逻辑错误
- 从阅读材料中提取可操作的见解
- 创建结构化学习笔记或学习摘要
- 比较多个研究来源
- 应用特定的思维框架（SCQA、心智模型等）
- 提供URL或长篇内容，意图深入理解

## 响应模式

当用户提供分析内容时：

### 1. 快速评估（15秒）
- 识别内容类型（文章/论文/指南/观点/案例研究）
- 检查用户是否指定了深度级别或框架
- 记录用户声明的目标（问题解决/学习/写作/决策/好奇心）

### 2. 初始化分析（对话式）

如果不确定，请简要询问导向性问题：
- "你的主要目标是什么？"（问题解决/学习/写作/决策/好奇心）
- "深度如何？"（快速15分钟/标准30分钟/深度60分钟/研究120分钟以上）
- "有特定的框架吗？"（或根据内容类型自动建议）

**默认情况下，如果用户没有指定**：级别2（标准，30分钟），自动选择框架

有关根据内容类型自动选择规则的详细信息，请参阅`references/guides/framework_selection.md`。

### 3. 进行分析

**始终从结构化理解开始**：
- 提取核心论点（1句话）
- 应用SCQA框架（`references/frameworks/quick/scqa.md`）
- 运行5W2H完整性检查（`references/frameworks/quick/5w2h.md`）

**然后根据深度级别应用框架**：

- **级别1**（15分钟）：SCQA + 5W2H → 前3个见解 + 1个行动
- **级别2**（30分钟）：添加批判性思维 + 逆向思维
- **级别3**（60分钟）：添加系统思维
- **级别4**（120分钟以上）：添加通过web_search的跨来源比较

根据需要加载框架参考文件。有关详细工作流程，请参阅`references/guides/workflow_guide.md`。

### 4. 生成定制输出

根据用户声明的目标格式化输出：
- **问题解决**：解决方案 + 行动计划 + 风险缓解
- **学习**：概念笔记 + 验证问题
- **写作**：论点 + 证据 + 引用 + 批判性分析
- **决策制定**：情景分析 + 推荐
- **好奇心**：关键见解 + 有趣的模式 + 兔洞

有关模板的详细信息，请参阅`references/templates/output_formats.md`。

### 5. 知识激活

始终以以下内容结束：
- 🎯 前3个收获（见解 + 为什么它很重要 + 每个行动）
- 💡 快速胜利（在接下来的24小时内尝试的一件事）
- 🔗 下一步（深化或应用）
- 🧭 使用的框架（应用的清单）

### 6. 适应用户信号

在整个对话中，读取信号并调整：
- 用户想要简洁 → 切换到级别1模式
- 用户质疑分析 → 倾向于批判性思维 + 逆向思维
- 用户询问“如何使用” → 专注于行动计划
- 用户想要多个观点 → 从不同角度应用批判性思维
- 用户提到风险 → 立即应用逆向思维
- 用户询问关于联系 → 使用系统思维

有关详细交互模式的详细信息，请参阅`references/guides/interaction_guide.md`。

## 分析深度级别

| 级别 | 时间 | 框架 | 输出 |
|-------|------|-----------|---------|
| **级别 1（快速）** | 15min | SCQA + 5W2H | 结构 + 空缺 + 前3个见解 + 1个行动 |
| **级别 2（标准）** | 30min | + 批判性思维 + 逆向思维 | 论点评估 + 风险分析 |
| **级别 3（深度）** | 60min | + 系统思维 | 关系映射 + 利用点 |

## 质量标准

每次分析都必须：
- ✅ 忠实于原始内容（无歪曲）
- ✅ 区分事实和观点
- ✅ 从文本中提供具体例子
- ✅ 适当应用框架（不要强行套用）
- ✅ 与用户声明的目标和背景相关联
- ✅ 以具体、可操作的步骤结束
- ✅ 引用具体部分（段落编号、引用）

避免：
- ❌ 使用所有框架感到不知所措（尊重深度级别）
- ❌ 没有解释的学术术语
- ❌ 没有应用的分析
- ❌ 直接复制（综合）
- ❌ 表面化地应用框架

有关完整质量检查表的详细信息，请参阅`references/guides/quality_standards.md`。

## 渐进式披露设计

此技能使用三级加载：
1. **元数据**（始终加载）：名称 + 描述（约100个单词）
2. **SKILL.md**（触发时加载）：使用指南（约150行）
3. **参考**（需要时加载）：详细框架和指南

仅在以下情况下加载参考文件：
- 用户选择更深的分析级别
- 请求或需要特定框架
- 需要针对复杂情况的详细指导

这使上下文高效，同时提供全面的功能。

## 高级用法

### 定制框架组合
用户可以请求特定的组合：
- "使用SCQA + 逆向思维" - 结构化 + 风险分析
- "应用批判性思维 + 系统思维" - 质量检查 + 关系映射
- "5W2H + 批判性思维" - 完整性 + 质量检查

### 递进深化
开始轻松，提供更深入的分析：
- 在级别1之后：“想要对任何部分进行更深入的分析吗？”
- 分析过程中： “我们应该应用[X框架]来探索这一点吗？”
- 根据参与度：逐步添加框架

### 针对特定领域的优化
自动针对内容类型进行优化（请参阅`framework_selection.md`）：
- **商业/战略**：SCQA + 逆向思维 + 系统思维
- **技术/研究**：5W2H + 批判性思维 + 系统思维
- **个人发展**：SCQA + 逆向思维 + 批判性思维
- **决策制定**：逆向思维 + SCQA + 系统思维
- **创意**：SCQA + 批判性思维 + 系统思维

**记住**：目标是洞察和行动，而不是框架完成。将框架用作揭示理解的工具，而不是作为完成清单。思考质量 > 应用框架的数量。

**渐进式方法**：从用户的需求开始，随着他们的参与提供更多深度。读取信号，相应地进行调整。
