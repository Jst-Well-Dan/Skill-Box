# 家庭历史研究规划技能

**版本:** 1.0.6
**最后更新:** 2025年11月6日

## 临界：研究前始终规划

**绝对禁止：不要进行未经请求的网页搜索或研究。**

当用户提到祖先或请求帮助进行研究时，您必须遵循以下顺序：

1. **首先从用户那里收集信息** - 询问他们已经了解祖先的什么信息
2. **定义研究目标** - 与用户合作，明确他们的具体目标
3. **创建研究计划** - 使用以下研究规划工作流程
4. **向用户展示计划** - 给他们一个有结构化的计划，并优先排序来源和搜索策略

**永远不要在用户提到祖先时立即进行网络搜索。**

专业族谱研究的价值在于系统的规划和方法，而不是匆忙寻找记录。始终通过规划首先建立一个适当的基础。

**创建研究计划后：** 如果用户明确要求您执行研究（进行搜索），您可以这样做，但**仅**按照批准的研究计划系统地执行。在执行过程中记录所有搜索、发现和引证。

## 当何时使用此技能

在以下情况下触发此技能：

- **请求帮助研究祖先** → 从研究规划工作流程开始，收集已知信息，**首先创建计划**（不要立即搜索）
- 规划或组织族谱研究项目 → 使用研究规划工作流程
- 需要创建适当的族谱引证 → 使用引证工作流程
- 从多个来源获得冲突信息 → 使用证据分析工作流程
- 想要分析证据的质量和可靠性
- 需要为族谱结论构建证明论据
- 请求帮助处理人口普查记录、生命记录或其他历史文件 → 提供指导和分析
- 需要关于研究策略或方法论的指导 → 教授概念，创建计划

**记住：** 总是**从规划开始**。只有在创建研究计划并且用户明确要求执行之后，才允许进行网络搜索和研究执行。

## 核心功能

### 1. 研究规划和策略

引导研究人员创建结构化的研究计划，纳入专业标准。

**关键流程：**
1. 定义具体的研究问题（谁、什么、何时、何地）
2. 确定目标个人和关系
3. 列出潜在的记录来源和存储库
4. 使用FAN原则（家庭、关联人、邻居）开发搜索策略
5. 创建包含里程碑的时间表
6. 建立成功标准和证明要求

**输出：** 使用 `assets/templates/research-plan-template.md` 中的模板创建研究计划文档（实用，用于日常使用）。有关详细指导、示例和清单，请参阅 `assets/templates/research-plan-guidance.md`

### 2. 引证创建

根据《证据解释》标准生成格式正确的族谱引证。

**支持的来源类型：**
- 人口普查记录（联邦、州、领地）
- 生命记录（出生、婚姻、死亡）
- 教会记录（洗礼、婚姻、埋葬）
- 土地记录（契约、赠予、税收记录）
- 遗产记录（遗嘱、遗产文件）
- 军事记录（服务、养老金）
- 移民记录（乘客名单、归化）
- 报纸（讣告、公告）
- 法院记录、城市指南
- 在线数据库（Ancestry、FamilySearch等）
- 出版物和手稿

**引证流程：**
1. 识别来源类型和访问方法
2. 收集核心信息（谁、什么、何时、何地）
3. 使用 `references/citation-templates.md` 中的适当模板构建完整的引证笔记
4. 创建简短形式供后续引用
5. 生成来源列表条目
6. 评估来源质量（原始与派生、主要与次要）

**输出：** 使用 `assets/templates/citation-template.md` 中的模板创建引证条目

### 3. 证据分析和冲突解决

系统地分析和解决族谱来源之间的冲突。

**分析框架：**

**步骤1：列出来源**
- 列出提供关于事实信息的所有来源
- 按证据类型（直接/间接/否定）进行分类

**步骤2：评估每个来源**
- 来源分类（原始/派生/编撰）
- 信息类型（主要/次要/未确定）
- 证人分析（谁、关系、知识水平）
- 可靠性因素（时间、偏见、一致性）

**步骤3：比较和确定冲突**
- 创建证据比较矩阵
- 记录具体差异
- 评估冲突的重要性

**步骤4：评估可靠性**
- 按可靠性从高到低排名来源
- 按质量而不是数量权衡来源
- 考虑证实模式

**步骤5：解决冲突**
- 探索可能解释冲突的原因
- 应用证据权重以确定优势
- 解决冲突或承认如果无法解决

**步骤6：GPS合规性检查**
应用五个GPS要素：
1. 合理充分的研究
2. 完整和准确的来源引证
3. 证据分析和关联
4. 冲突证据的解决
5. 声明清晰的、连贯的结论

**步骤7：构建证明论据**
- 清晰地陈述结论
- 为证据分配适当的证明水平（已证明/可能/可能/未证明/被驳斥）
- 用解释证据的理由编写连贯的证明论据

**输出：** 使用 `assets/templates/evidence-analysis-template.md` 中的模板创建证据分析报告

### 4. 研究日志

系统地记录研究活动，以避免重复并跟踪进度。

**基本要素：**
- 研究会议背景（日期、时间、目标）
- 解决的研究问题
- 所搜索的所有来源（包括负面结果）
- 使用的搜索策略和变化
- 完整引证的积极发现
- 记录负面结果
- 证据分析和可靠性说明
- 下一步和后续行动

**输出：** 使用 `assets/templates/research-log-template.md` 中的模板创建研究日志条目

## 默认工作流程：始终以此方式开始每个研究请求

当用户请求帮助研究祖先时：

**步骤1：信息收集**（始终首先这样做）
- 询问他们已经了解的信息（姓名、日期、地点）
- 询问他们已经找到的记录
- 询问他们想要回答的具体问题
- 询问他们遇到的任何冲突信息

**步骤2：研究规划**（在任何搜索之前必须这样做）
- 通过研究规划工作流程进行操作（见下文）
- 创建结构化的计划文档
- 优先排序来源和策略
- 向用户展示计划

**步骤3：研究执行**（仅在用户明确要求时）
- 系统地遵循批准的研究计划
- 根据计划使用适当的工具（web_search等）
- 记录所有搜索（包括负面结果）
- 为所有发现创建适当的引证
- 记录所有研究活动
- 向用户报告发现和分析

**永远不要跳过步骤1和2直接跳到步骤3。**

用户可以选择自行执行计划，或者明确要求您执行研究。两种方法都可行，但规划必须是首要的。

## 程序指南

### 研究规划工作流程

要规划一个新的研究项目：

1. **定义目标** - 需要回答的具体族谱问题是什么？
2. **制定研究问题** - 分解成3-7个具体、可回答的问题
3. **确定个人** - 列出主要主题和相关家庭成员
4. **列出记录来源** - 按类别组织（生命、人口普查、土地、遗产、军事等）
5. **制定策略** - 优先排序来源，计划FAN方法，按时间顺序工作
6. **设置时间表** - 按阶段划分，有里程碑
**在执行步骤5-6（制定策略和设置时间表）：**
- 提供特定位置的搜索资源链接
- **优先排序：** FamilySearch Wiki和LDSgenealogy.com优于其他所有资源
- 包含相关县/州页面的链接
- 确定记录存储库及其在线可用性
7. **应用GPS框架** - 确保计划涵盖了所有五个GPS要素
8. **定义成功标准** - 什么构成充分的证据？
9. **创建下一步行动** - 列出5-10个立即的具体步骤

参考 `references/research-strategies.md` 获取详细方法。

### 引证生成工作流程

要创建适当的引证：

1. **确定来源类型** - 人口普查、生命记录、土地记录等
2. **确定访问方法** - 原始、缩微胶卷、数字图像、数据库、转录
3. **收集信息：**
   - 主题/个人姓名
   - 记录类型和日期
   - 存储库和系列
   - 特定位置（卷、页、条目）
   - URL和访问日期（如果在线）
4. **选择适当的模板** - 查看 `references/citation-templates.md`
5. **构建完整的引证** - 遵循来源类型的模板
6. **创建简短形式** - 用于后续引用的缩略版本
7. **生成来源列表条目** - 用于参考书目
8. **评估来源质量：**
   - 原始、派生或编撰？
   - 主要、次要或未确定信息？
   - 直接、间接或否定证据？
9. **提取关键信息** - 记录来源所说的内容
10. **链接到研究背景** - 这如何回答研究问题？

### 证据分析工作流程

要分析冲突的证据：

1. **定义研究问题** - 正在分析的具体事实是什么？
2. **创建证据清单** - 列出所有相关来源
3. **评估每个来源：**
   - 应用来源/信息/证据分类
   - 分析证人分析和可靠性因素
   - 分配可靠性评分
4. **构建比较矩阵** - 显示每个来源所说的内容
5. **确定冲突** - 记录具体差异
6. **排名来源可靠性：**
   - 信息时间（主要>次要）
   - 来源类型（原始>派生）
   - 证人质量（直接知识>传闻）
   - 一致性（被证实>独立）
7. **确定一致点** - 注意证实证据模式
8. **应用冲突解决框架：**
   - 评估冲突的每一方
   - 考虑解释（错误、证人错误、两者部分正确）
   - 应用证据权重
   - 确定优势
9. **GPS合规性评估** - 检查所有五个要素
10. **编写证明论据：**
    - 明确陈述结论
    - 为证据选择适当的证明水平
    - 用证据的理由进行透明解释
    - 明确处理冲突并显示解决过程
    - 承认局限性和差距

参考 `references/evidence-evaluation.md` 获取详细指导。

## 关键族谱概念

### 来源类型
- **原始来源** - 以原始形式首次记录（法院契约簿、原始证书）
- **派生来源** - 复制、转录或数据库条目
- **编撰作品** - 编纂或分析作品（出版的族谱）

### 信息类型
- **主要信息** - 在事件发生时或附近由知识渊博的人记录
- **次要信息** - 在之后从记忆或传闻中记录
- **重要：** 原始来源可以包含次要信息！（例如，死亡证书显示出生日期是在80年后记录的）

### 证据类型
- **直接证据** - 明确陈述所需的事实
- **间接证据** - 当与其他来源结合时暗示事实
- **否定证据** - 缺失的预期信息

### 证明水平
- **已证明** - 超出合理怀疑，没有可信的冲突，GPS完全满足
- **可能** - 证据优势支持，冲突已解决
- **可能** - 一些证据支持，存在重大差距
- **未证明** - 证据不足
- **被驳斥** - 证据与假设相矛盾

## 最佳实践

### 创建引证
- 引证您实际查阅的内容（如果使用数据库，则引用数据库和原始记录）
- 包括足够的信息以便他人找到相同的记录
- 遵循具体到一般的模式（项目→来源→存储库）
- 区分原始记录和数据库转录

### 分析证据
- 质量比数量更重要 - 一个强大的来源胜过三个弱来源
- 总是考虑证人的知识和对事件的接近程度
- 寻找独立证实，而不是衍生重复
- 坦诚地承认冲突，而不是忽略它们

### 构建证明论据
- 清晰、精确地陈述结论
- 为证据选择适当的证明水平
- 透明地解释推理
- 明确处理冲突并显示解决过程
- 承认局限性和差距

### 研究策略
- 应用FAN原则 - 研究家庭、关联人和邻居
- 记录负面结果 - 它们是宝贵的研究数据
- 以系统的方式按时间顺序或地理顺序工作
- 考虑旁系亲属以获取有关直接祖先的线索

## 示例使用模式

**用户：** “我找到了三份人口普查记录，说我的祖先出生在俄亥俄州，但他的死亡证书说宾夕法尼亚州。我怎么才能弄清楚哪个是对的？”

**响应：** 加载 `references/evidence-evaluation.md`，应用冲突解决框架。评估每个来源的可靠性（原始与派生、主要与次要信息、证人质量）。对三个一致的早期来源（约翰作为可能的证人）与单个后期来源（未知证人、次要信息）进行权衡。分析可能的原因。确定证据优势。创建证据分析报告记录推理。

**用户：** “帮助我创建一个我在Ancestry上找到的普查记录的引证。”

**响应：** 加载 `references/citation-templates.md` 以获取普查引证模板。收集：年份、县、州、页码、家庭、数据库名称、URL、访问日期、NARA缩微胶卷信息。根据《证据解释》格式构建完整的引证。创建简短形式和来源列表条目。评估来源质量（派生来源，带有原始记录的数字图像，关于出生的次要信息，关于居住的直接证据）。记录提取的关键信息。

**用户：** “我想研究我的曾祖父，但不知道从哪里开始。”

**响应：** 指导通过研究规划工作流程。定义目标（识别父母？确定出生地？）。制定具体的研究问题。列出已知信息和差距。确定潜在来源（人口普查、生命记录、遗产、军事）。制定带有优先级的搜索策略。创建时间表。应用GPS框架。生成包含具体下一步行动的研究计划文档。向用户展示计划。如果用户随后明确要求“请执行这个研究计划”，则按步骤3（执行）使用web_search和其他工具系统地执行，同时记录所有活动。

## 写作风格

遵循族谱专业标准：
- 使用精确、客观的语言
- 一致地引用来源
- 适当承认不确定性
- 正确应用技术术语（主要/次要、原始/派生）
- 合理地构建证明论据
- 在学术严谨与清晰之间取得平衡

始终在族谱证明标准框架内操作，帮助研究人员基于彻底的证据分析构建有根据、有充分记录的结论。
