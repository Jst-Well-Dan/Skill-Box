# 竞争对手广告提取器

这项技能可以从广告库中提取您的竞争对手的广告，并分析哪些方法有效——他们强调的问题、针对的使用案例和引起共鸣的文案/创意。

## 使用此技能的时机

- 研究竞争对手的广告策略
- 寻找您自己广告的灵感
- 理解市场定位
- 识别成功的广告模式
- 分析有效的信息
- 发现新的使用案例或痛点
- 使用经过验证的概念来规划广告活动

## 此技能的功能

1. **提取广告**：从Facebook广告库、LinkedIn等网站抓取广告。
2. **捕获截图**：保存所有广告的视觉副本。
3. **分析信息**：识别问题、使用案例和价值主张。
4. **分类广告**：按主题、受众或格式分组。
5. **识别模式**：找到常见的成功方法。
6. **提供见解**：解释为什么某些广告可能表现良好。

# Notion广告分析

## 概述
- 总广告数：23个活跃
- 主要主题：生产力（35%）、协作（30%）、模板（20%）、AI功能（15%）
- 广告格式：静态图片（60%）、视频（40%）
- CTA模式："免费试用"、"开始使用"

## 他们强调的关键问题

1. **信息散乱**（8个广告）
   文案："停止在10个不同的工具之间切换"
   为什么有效：许多团队面临的一个直接痛点

2. **会议过多**（5个广告）
   文案："用异步更新取代不必要的会议"
   为什么有效：后COVID远程工作的痛点

3. **丢失文档**（4个广告）
   文案："永远不要再问'那个文档在哪里？'了"
   为什么有效：普遍的工作场所挫败感

## 成功的创意模式

### 模式1：前后对比
- 展示混乱的工具景观 → 清洁的Notion工作空间
- 在6个表现良好的广告中使用
- 视觉隐喻立即清晰

### 模式2：功能展示
- 实际产品使用的GIF
- 在5秒内展示特定功能
- 用于新功能（AI、模板）

### 模式3：社会证明
- "加入2000万用户"的信息
- 客户标志
- 在4个针对企业的广告中使用

## 有效的文案

最佳标题：
1. "您的团队的知识，终于在一个地方"
   → 以利益为导向，直接解决痛点
   
2. "一站式工作空间"
   → 清晰的定位，广泛的吸引力
   
3. "真正帮助您工作的AI"
   → 解决AI怀疑论，实用的角度

最佳正文文案模式：
- 短句子（10个词以下）
- 关注结果而不是功能
- 包含具体数字（"减少会议50%"）

## 受众定位见解

基于广告变化：
- 创业家：个人生产力角度
- 团队领导：协作和对齐
- 企业：安全和合规提及
- 学生：免费计划、模板、组织

## 对您广告的建议

1. **测试“工具泛滥”的痛点**
   → 根据他们的广告频率，强烈的共鸣

2. **使用产品截图而不是抽象视觉**
   → 他们所有顶级广告都显示了实际的UI

3. **以问题为主，而不是解决方案**
   → "厌倦了X？"比“推出Y”表现更好

4. **保持文案不超过100个字符**
   → 他们最短的广告似乎出现频率最高

5. **测试前后对比视觉格式**
   → 他们在创意中证明的模式

4. **按受众细分**：针对不同的目标使用不同的信息
5. **比较平台**：LinkedIn与Facebook的信息不同

## 常见工作流程

### 广告活动规划
1. 提取竞争对手广告
2. 识别成功的模式
3. 记录他们信息中的差距
4. 发起独特的角度
5. 撰写测试广告变体

### 定位研究
1. 从5个竞争对手获取广告
2. 绘制他们的定位
3. 找到未被满足的角度
4. 开发差异化的信息
5. 对他们的方法进行测试

### 创意灵感
1. 按主题提取广告
2. 分析视觉模式
3. 注意色彩和布局趋势
4. 调整成功的模式
5. 创建原创变体

## 成功技巧

1. **定期监控**：每月检查变化
2. **广泛研究**：查看相邻的竞争对手
3. **保存一切**：建立参考库
4. **测试见解**：进行自己的实验
5. **跟踪性能**：对受启发的概念进行A/B测试
6. **保持原创**：用于灵感，而不是复制
7. **多个平台**：比较Facebook、LinkedIn、TikTok等
